## Introduction

ronfig is an [R](https://www.r-project.org/) package that enables intuitive
configuration of R projects via a single function, `load_config()`.

## Installing the package

You can install the latest release of ronfig from
[CRAN](https://cran.r-project.org/) with:

``` {.r}
install.packages("ronfig")
```

## Vignette

A brief overview of super is available [online](https://timtaylor.codeberg.page/ronfig/vignette.html) and in the vignette distributed with the package:

``` {.r}
vignette("ronfig", package = "ronfig")
```
